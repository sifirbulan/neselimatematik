# AI Service

Python tabanlı matematik ve AI katmanı burada konumlanacak.

İlk servis sınırları:

- `question-analyzer`: sınıf/sınav, konu, kazanım, zorluk ve soru tipi çıkarımı
- `math-solver`: sembolik/nümerik çözüm
- `verifier`: bağımsız çözüm doğrulama
- `teacher`: öğrenci seviyesine göre açıklama
- `assessment`: kişiselleştirilmiş soru/test üretimi
- `orchestrator`: modelleri ve araçları görev bazında yönlendirme
